Scam Pause

Scam Pause is a scam-awareness brand publishing short, AI-narrated videos on YouTube Shorts, TikTok, Instagram and Facebook. Each video explains a common scam and how to pause, check, and protect yourself.

About this app

The Scam Pause application uses the YouTube Data API v3 solely to upload videos to the Scam Pause YouTube channel, which we own. It does not access, collect, or store data from viewers or the public.
